# Simple XSS Challenge

## 문제 설명

이 웹사이트는 사용자 메시지를 게시판에 표시하는 간단한 방명록입니다. 관리자는 정기적으로 방명록을 확인하고 있습니다. 
XSS 취약점을 이용해 관리자의 쿠키를 탈취하고 플래그를 획득하세요.

## 시작하기

1. 문제 서버에 접속합니다: `http://challenges.example.com:8080`
2. 방명록에 메시지를 남길 수 있습니다.
3. 관리자는 주기적으로 새 메시지를 확인합니다.

## 목표

관리자의 쿠키에 저장된 플래그를 탈취하세요.

## 힌트

- 입력 필드에 어떤 필터링이 적용되어 있는지 확인해보세요.
- 입력한 내용이 페이지에 어떻게 반영되는지 살펴보세요.
- XSS 페이로드를 통해 외부 서버로 데이터를 전송하는 방법을 고려해보세요.
