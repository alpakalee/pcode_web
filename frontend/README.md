# 프론트엔드 (Frontend)

이 디렉토리는 P-CODE 웹사이트의 프론트엔드 코드를 포함하고 있습니다.

## 기술 스택

- **언어**: HTML5, CSS3, JavaScript (ES6+)
- **스타일링**: 자체 CSS (향후 프레임워크 도입 예정)
- **통신**: Fetch API

## 구조

```
frontend/
├── index.html           # 메인 페이지
├── login.html           # 로그인 페이지
├── register.html        # 회원가입 페이지
├── css/                 # 스타일시트 파일 (향후 추가 예정)
├── js/                  # 자바스크립트 파일 (향후 추가 예정)
├── images/              # 이미지 파일 (향후 추가 예정)
└── components/          # 재사용 가능한 컴포넌트 (향후 추가 예정)
```

## 페이지 설명

### 메인 페이지 (index.html)

- 웹사이트 소개 및 주요 기능 안내
- 로그인/회원가입 버튼
- CTF 플랫폼 및 게시판 링크
- 최근 업데이트 정보 표시

### 로그인 페이지 (login.html)

- 사용자 로그인 기능
- 세션 관리 및 인증 처리
- '로그인 상태 유지' 옵션

### 회원가입 페이지 (register.html)

- 새 사용자 등록 기능
- 유효성 검증 (사용자명, 이메일, 비밀번호)

## 개발 가이드라인

### HTML 코딩 스타일

- 시맨틱 HTML 태그를 사용하세요 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` 등)
- 들여쓰기는 4칸 공백을 사용하세요
- 클래스명은 의미 있고 명확하게 지정하세요
- 모든 HTML 파일은 유효한 HTML5 문서여야 합니다

### CSS 코딩 스타일

- CSS 클래스명은 BEM(Block Element Modifier) 방법론을 따르세요
- 선택자는 가능한 한 구체적으로 사용하세요
- 미디어 쿼리를 사용하여 반응형 디자인을 구현하세요
- CSS 변수를 활용하여 일관된 스타일을 유지하세요

### JavaScript 코딩 스타일

- ES6+ 문법을 사용하세요
- 변수는 `const`와 `let`을 사용하세요 (`var` 사용 금지)
- 함수는 화살표 함수로 작성하세요
- 비동기 작업은 async/await를 사용하세요
- 모든 API 호출에는 적절한 에러 핸들링을 추가하세요

## 기여 방법

1. 개발 전 이슈를 생성하세요
2. 기능 개발은 새 브랜치에서 진행하세요: `feature/기능명`
3. 버그 수정은 새 브랜치에서 진행하세요: `fix/버그명`
4. 변경사항은 크로스 브라우저 테스트와 함께 제출하세요
5. Pull Request를 생성하고 코드 리뷰를 요청하세요
